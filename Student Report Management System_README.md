# Java Student Report Management System

## Project Overview
A console-based Java application to manage student records. Users can **add students, view all students**, and automatically calculate **GPA**. All data is stored in a text file (`students.txt`) for persistence.  

## Features
- Add student (name, roll number, marks)  
- Calculate GPA automatically  
- View all students in a table-like format  
- Store student data in a text file
